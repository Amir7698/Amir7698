# Amirhossein Mohtashami

Embedded firmware engineer based in Turin, Italy. M.Sc. in Electronic Engineering, Politecnico di Torino.

I write firmware in C and C++ for STM32 microcontrollers and embedded Linux, and I like the part where the code meets the hardware: measuring, debugging and testing on the bench.

## Projects

| Project | What it is |
|---|---|
| [pressure-alarm-node](https://github.com/Amir7698/pressure-alarm-node) | STM32 pressure monitor for medical gas lines: 4-20 mA input with timer-triggered ADC and DMA, alarm state machine with PC unit tests |
| [j1939-monitor](https://github.com/Amir7698/j1939-monitor) | SAE J1939 CAN monitor for embedded Linux in C++11: SocketCAN, BAM transport protocol, DM1, GoogleTest, Docker, CI |
| [stm32-bldc-firmware](https://github.com/Amir7698/stm32-bldc-firmware) | Bare-metal STM32F407 BLDC motor controller with complementary PWM and dead-time, simulated in Renode |
| [stm32-bare-metal](https://github.com/Amir7698/stm32-bare-metal) | Register-level GPIO, SPI and I2C drivers for STM32, without HAL |
| [embedded-interview-prep](https://github.com/Amir7698/embedded-interview-prep) | Embedded systems exercises: C, RTOS, protocols, Linux BSP |
